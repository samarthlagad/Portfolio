# Samarth Lagad — Personal Portfolio

> A modern, interactive personal portfolio showcasing my journey in software engineering, cybersecurity, and secure software development.

## 🌐 About the Project

This repository contains my personal portfolio website, designed to present my technical skills, projects, learning journey, certifications, and contact information through an immersive and responsive web experience.

The website combines a dark, futuristic aesthetic with smooth animations, interactive elements, and a cybersecurity-inspired visual identity.

## ✨ Features

* **Interactive Hero Section** — Animated typing effect introducing my professional interests.
* **Modern UI Design** — Dark theme with cyan, purple, and pink gradients.
* **Animated Background** — Canvas-based starfield and subtle atmospheric effects.
* **Responsive Navigation** — Mobile-friendly menu with smooth section navigation.
* **Skills Showcase** — Highlights programming languages, security knowledge, and development tools.
* **Project Gallery** — Displays projects with interactive cards and hover effects.
* **Scroll Animations** — Reveal effects, reading-progress indicators, and animated section headings.
* **Interactive Project Cards** — Tilt and spotlight effects for an immersive experience.
* **Portfolio Journey** — Timeline for academic milestones and professional development.
* **Certifications & Achievements** — Dedicated section for accomplishments.
* **Contact Form** — Validates user input and opens a prefilled email draft.
* **Interactive Terminal** — Hidden terminal interface with custom commands.
* **Accessibility Support** — Keyboard navigation and reduced-motion preferences.
* **Back-to-Top Button** — Quickly returns visitors to the beginning of the page.

## 💻 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/samarthlagad/samarthlagad.github.io.git
```

### 2. Navigate to the project directory

```bash
cd samarthlagad.github.io
```

### 3. Open the website

Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code for local development.

No package installation or build process is required for the HTML, CSS, and JavaScript version.

## ⚙️ Customization

To personalize the portfolio:

1. Update the introduction and About section in `index.html`.
2. Add your education, experience, and achievements to the Journey section.
3. Replace the placeholder certification cards with actual credentials.
4. Add your portrait at `assets/photo.jpg`.
5. Add your resume as `resume.pdf`.
6. Update project descriptions and repository links.
7. Replace the placeholder LinkedIn URL with your profile link.
8. Modify `css/style.css` to customize colors, typography, and animations.
9. Update `js/main.js` to customize interactive features.
